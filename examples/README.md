# Beispiel-Konfiguration

Generisches Beispiel-Arbeitsverzeichnis für Entwicklung, Tests und als Vorlage für neue Nutzer (siehe „Settings-Datei" und „Arbeitsverzeichnis mit mehreren Plänen" in [Docs/02-Architektur-und-MCP.md](../Docs/02-Architektur-und-MCP.md)). Bewusst generisch statt persönlich benannt.

- [settings.example.toml](settings.example.toml) – Beispiel-Settings-Datei. Zum Verwenden nach `settings.toml` kopieren und `working_directory` anpassen.
- Ein Beispiel-Plan-Ordner (z. B. `sample-plan/`) kommt hinzu, sobald das JSON-Schema einer Plan-Datei feststeht (siehe [Docs/10-Roadmap.md](../Docs/10-Roadmap.md), Meilenstein 1 Epic 1.4 / Meilenstein 2) – aktuell existiert noch keiner.
